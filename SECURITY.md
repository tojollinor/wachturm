# Sicherheitsmeldungen

Bitte keine Zugangsdaten, PINs, Konfigurationsexporte oder vollständigen personenbezogenen Protokolle in öffentlichen Issues veröffentlichen.

Für sicherheitsrelevante Schwachstellen bevorzugt die private Meldemöglichkeit unter **Security → Advisories → Report a vulnerability** verwenden, sofern sie im Repository angeboten wird. Falls sie nicht verfügbar ist, kann ein Issue ohne ausnutzbare Details um einen privaten Kontaktweg bitten.

Bedienrechte und PIN-Prüfung gehören auf den Server. Änderungen an der Oberfläche dürfen diese Prüfungen nicht ersetzen oder umgehen. Ereignisse externer Taster allein gelten nicht als Identitätsnachweis.
